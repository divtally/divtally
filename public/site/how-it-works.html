How it works

Paste a build, see what it costs. Here is exactly what happens, which servers are involved, and what is stored — in plain words.

How to use it
  • Paste build link or import code → Appraise. Gems, uniques, currency priced instantly.
  • Rares start unpriced — total is a floor. Header counts what's left.
  • Fastest path: install the DivTally browser extension → rares price automatically from your own connection, live status per item. Auto-scan toggle on = every build you load scans itself.
  • No extension: open search on a rare → official trade site, pre-filtered → copy any listing's whisper → paste in the row. Or type 35c / 2 div. Total updates instantly.
  • Popular builds: rares may arrive pre-priced from the community cache — marked unverified, dot instead of checkmark.
  • Untick any item → excluded from totals ("what's it cost without the chase ring").
  • MIN / MEDIAN / HIGH top-right = budget tiers. Chaos totals, divines alongside.
  • pob import = copy the build's import code. Search all again = re-price everything fresh.
  • Can't price it honestly → trade link and no number, never a made-up one.
  • Prices are a snapshot; they move.

Rares price on your machine, never on a server — full story below.

Where every number comes from

Two kinds of items, two different sources:

  • Gems, currency, and named uniques are priced from the poe.ninja economy (a public, cache-friendly dataset). These show up as real numbers the moment a build loads.
  • Rares (and magic items, and uniques poe.ninja doesn't list) can't be priced that way — every rare is unique. For each one you get a ready-made trade search and price it yourself, one of four ways:
  • Free
    The community cache. If another visitor (or a volunteer's daily seeding run) already priced this exact item recently, its price is filled in for you automatically. Short-lived (24 hours) and always exact-match. You can turn this off below.
  • Rung 1
    You paste a price. Click open search on a rare, find a comparable listing on the trade site, copy its buyout (the whisper), and paste it back here. Type 35c or 2 div if you already know. It folds into your total and is remembered on your device for that build.
  • Rung 2
    The DivTally browser extension (optional; download from GitHub while store listings are in review). It runs those same trade searches from your browser and IP — logged out — and fills the cheapest buyout in automatically. Nothing on our side ever touches the trade API.
  • Rung 0
    Run it locally. The whole thing is open source; you can run the desktop/CLI version on your own machine if you'd rather not use the website at all.
Why the split Neither poe.ninja nor the trade site lets a random website read prices directly from a visitor's browser (no cross-origin access). So hands-free rare pricing needs code running with permission on your own machine — the extension, a userscript, or the local app. Everything else stays free and installs nothing.

These are every server DivTally contacts. You can verify them in your browser's Network tab.

The build function reads poe.ninja — plus, only when you paste a PoB paste-link, the paste service you linked (pobb.in / pastebin.com) to fetch that code. The cache Worker reads and writes only its own key/value store. Item and currency pictures load as plain images from GGG's public CDN (web.poecdn.com) — no cookies, nothing about you. Fonts are served from this site, not Google. The only requests to pathofexile.com itself come from your own browser — a tab you opened, or the extension you chose to install.

What's stored, and where

On your device (localStorage — never leaves your browser)

KeyWhat
bpc_manual:…Prices you pasted for a build's rares, so they survive a reload.
bpc_purchased:…Which items you ticked as "already bought".
bpc_recent_buildsThe builds you looked up, for the "saved characters" shortcuts.
bpc_status_v2 / bpc_league / bpc_tierYour control preferences.
bpc_cache_optoutWhether you've opted out of the shared cache (below).

No account, no login, and no cookies we set — no analytics, no ad/tracking pixels, no third-party scripts. The only third-party server your browser touches on a normal page load is GGG's image CDN (web.poecdn.com) for item pictures; it sets nothing and learns nothing but that an icon was fetched. Clear your browser storage and everything on your device is gone.

In the shared community cache (short-lived, public prices only)

When a rare is priced on a real machine, its price only is stored so the next visitor with the same build sees it too. Each entry is a chaos number plus a listing count and the trade link — keyed by a hash of the item's league + name + mods. It holds no character name, account, or anything identifying, and every entry expires after 24 hours. Unpriceable items are simply left blank (a link, never a made-up number).

This cache is open — the recipe is public, so anyone can contribute (that is how the extension shares your results back). So the site treats it as untrusted: a cached price is always shown as community-submitted and unverified, never with the green "verified" dot a poe.ninja price gets, and its confidence is computed from the listing count on our side — whatever a sender claims is ignored. Values are capped to sane magnitudes, and a per-contributor daily write limit keeps one script from flooding it. It is a convenience, not a source of truth: to trust a number, click through to the live trade search.

Opt out of the shared cache

With this on (the default), your build reads cached rare prices, and prices produced on your machine (via the extension) are shared back. Turn it off and this site will neither read from nor write to the shared cache — you'll price every rare yourself.

Playing nice with the trade API (rate limits)

Grinding Gear Games publishes rate limits for their trade API and temporarily blocks IPs that ignore them. Because this site never calls that API, it can't cause you a problem. The two places trade calls do happen both behave:

  • The extension ships the same polite limiter the desktop app uses: it reads GGG's rate-limit headers, stays well under every window, honours Retry-After, and prices one search at a time. It runs logged-out (credentials: omit), so it's your per-IP anonymous limit — no account risk.
  • Clicking a trade link is just you opening the normal trade site in a tab, exactly as if you'd searched it by hand.

The extension, precisely

Optional, open source, and deliberately boring:

  • Only requests to pathofexile.com/api/trade/* and DivTally's own domain. Nothing else.
  • No access to your tabs, browsing history, or other sites. No cookies, no login, no POESESSID.
  • Distributed unminified through the browser stores (Chrome / Edge / Firefox — listings in review); until they are live, the identical build is published on the GitHub releases page. Source readable in the repo either way.
  • The site is fully usable without it — it only saves you the copy-paste.
